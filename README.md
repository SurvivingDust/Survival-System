Features


Health System:

&#x20;Tracks player health values

&#x20;Supports damage and healing

&#x20;Integrates with UI progress bars

&#x20;Handles player death events

Hunger System:

&#x20;Hunger decreases over time

&#x20;Starvation damages the player when hunger reaches zero

&#x20;Updates UI dynamically

Thirst System:

&#x20;Thirst decreases over time

&#x20;Dehydration damages the player when thirst reaches zero

&#x20;Updates UI dynamically

Mana System:

&#x20;Tracks player mana values

&#x20;Supports future abilities and gameplay mechanics

&#x20;Integrates with UI progress bars

Consumable Items:

&#x20;Restores survival statistics

&#x20;Interacts with player attributes

&#x20;Supports multiple item effects

Death and Respawn:

&#x20;Detects player death

&#x20;Executes respawn logic

&#x20;Restores player state after respawn
