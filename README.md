# UE5 Survival System

## Overview

A survival system built in Unreal Engine 5 using Blueprint Visual Scripting.

## Features

- Health System
- Hunger System
- Thirst System
- Mana System
- Consumable Items
- Death and Respawn
- Damage Over Time
- UI Integration
